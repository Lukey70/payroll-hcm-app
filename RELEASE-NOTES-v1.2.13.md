# Payroll/HCM App v1.2.13

Released 9 November 2026.

- Relief-style Casual Input in Payroll Tools and MSS Payment Processing, with employee/position replacement details, daily schedules, history and automatic pay-period routing.
- Casual earnings are read-only in Additional Earnings. Select an employee and record for other earnings; manage casual earnings through Casual Input.
- Managers cannot delete casual input after its payment is finalised. A prefilled Payroll support request is available; Payroll retains deletion and recovery authority.
- Structured manager requests include Record Number, single-record defaults and New Concurrent Record for commencements. Requests remain instructions for Payroll processing.
- Casual Job Data uses the configured Casual position with no Reports To. Multi-record calendars show NRD before non-casual commencement.

Casual Input saves daily earnings into the relevant work-date pay periods. Corrections to settled earnings generate retro adjustments; deletion recovers paid dates once and preserves finalised payslips. Late entries for closed work periods stay deletable by managers until their actual payment is finalised.

MSS Casual Input uses the same active casual employee pool as Payroll because casual records have no Reports To. Other MSS Additional Earnings remains limited to direct reports. New Concurrent Record is a commencement request option; variations, movements and terminations select existing records. New employees use initial record 0 when Payroll processes the commencement.

Back up browser data before replacing files. Extract the complete package and open index.html or serve the extracted folder. Existing browser-local data and finalised payslips are retained. This remains a browser-local prototype; data is not shared across browsers or devices.
