Payroll/HCM App v1.1.32

DEPLOYMENT
Upload all application files in this folder together. Before replacing an existing version, use Export Data and retain the JSON backup. v1.1.32 preserves the payrollAppData/localStorage structure and migrates it through DataStore.migrate().

IMPORTANT BEFORE UPDATE
Ensure at least one active employee's current Position Data record has "Access to Payroll Management" enabled. v1.1.32 now uses that effective position flag to decide whether the Payroll Management landing tile is visible.

LOGIN
- Select an active employee at login.
- Default password is 1234 for migrated/current employees unless a stored credential already exists.
- Employee Self-Service is shown for active users but is Coming Soon.
- Manager Self Service is shown only for MSS-enabled positions and is Coming Soon.
- Payroll Management opens the existing payroll application and is shown only for Payroll Management-enabled positions.

DATA
- Existing employees, Job Data, Position Data, payroll history, finalised payslips, leave, balances, deductions, Additional Earnings, certifications and alerts are preserved.
- loginCredentials is added to stored/exported data for future ESS password-change support.

See RELEASE-NOTES-v1.1.32.txt and test-results.txt for release details and actual verification results.
