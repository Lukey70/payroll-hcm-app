Payroll/HCM App v1.1.27

DEPLOYMENT
Upload all application files in this folder together. Before replacing an existing version, use Export Data and retain the JSON backup. v1.1.27 migrates existing saved data in place and preserves the payrollAppData/localStorage structure.

IMPORTANT UPGRADE BEHAVIOUR
- Existing v1.1.26 LSL reconciliation markers/history are preserved; the one-time LSL repair is not rerun simply because v1.1.27 is opened.
- Fixed-term Job Data is reconciled so New Fixed Term Contract / Expiry of Fixed Term sequences drive the authoritative contract end without creating a false employment break.
- Legacy saved leave/deduction/additional-earning data continues to be defaulted/migrated in place.
- Finalised historical payslips are not rewritten.

MAJOR CHANGES
- Deductions: unchanged historical End Dates no longer block saving a new ongoing Union Fees deduction; new/edited dates still validate normally.
- Additional Earnings: Special Responsibility Allowance (Days) = $20 per entered calendar day.
- Fixed term: Job Data extension workflow is authoritative for contract end and leave validation.
- Annual Leave: future forecast balance shown/used for booking; valid forecast-approved bookings survive later schedule/FTE changes; resignation can recover the actual outstanding forecast-approved Annual Leave deficit through a separate recovery line.

PAYROLL CONTROLS PRESERVED
- Persisted currentCycleId remains the authoritative open pay; the app does not select a cycle from today's date.
- Original anchor remains PPE 04/06/2026, period 22/05/2026–04/06/2026.
- Retro cut-off remains 03/05/2026.
- Finalisation remains manual.

TESTING
See test-results.txt and RELEASE-NOTES-v1.1.27.txt for actual automated/static/simulated/browser results and known limitations.
