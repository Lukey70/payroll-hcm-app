Payroll/HCM App v1.1.26

DEPLOYMENT
Upload all application files in this folder together. Before replacing an existing version, use Export Data and retain the JSON backup. v1.1.26 migrates existing saved data in place and preserves the payrollAppData/localStorage structure.

IMPORTANT UPGRADE BEHAVIOUR
- On first load, v1.1.26 runs a one-time 7-year/65-day LSL reconciliation for every saved employee.
- Each employee receives a separate notification describing corrections or explicitly stating that no action was taken.
- If recognised-service/audit history is insufficient to reconstruct a legacy LSL value reliably, the notification flags Review required rather than silently inventing a replacement.
- Finalised historical payslips are not rewritten.
- A one-time Personal Leave reconstruction also applies the >182-day break rule to existing recorded employment histories.

PAYROLL CONTROLS PRESERVED
- Persisted currentCycleId remains the authoritative open pay; the app does not select a cycle from today's date.
- Original anchor remains PPE 04/06/2026, period 22/05/2026–04/06/2026.
- Retro cut-off remains 03/05/2026.
- Finalisation remains manual.

MAJOR CHANGES
- LSL: recurring 7-year cycle; 65 working days / 13 weeks per completed cycle; new break and non-contributory-service rules.
- Terminations: accrued Annual Leave + accrued LSL payout for non-retirement; retirement also pays pro-rata LSL.
- Additional Earnings: Additional Hours rename; Meal $18/date; user-entered Travel; Motor Vehicle Single $25 / Return $50; user-entered Bonus.
- Deductions: ongoing Union Fees with blank End Date remains valid alongside other ongoing deductions.
