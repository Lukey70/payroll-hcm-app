Payroll/HCM App v1.1.17

Open index.html to run the client-side demonstration app. The demonstration login password remains 1234.

Before replacing an existing version, use Export Data and retain the JSON backup. Version 1.1.17 migrates existing v1.1.16 data without deleting employees, pay history, leave, deductions or certifications.

New in this release:
- Reports tab and Statement of Service report
- Reimbursement Additional Earnings type
- automatic 17.5% Annual Leave Loading
- historical Annual Leave Loading Retro audit/correction

The Statement of Service relies on complete Personal Details, Job Data, schedules, locations/departments and Leave Without Pay history. Review generated statements before issuing them.

This is a demonstration application and is not certified production payroll software.
