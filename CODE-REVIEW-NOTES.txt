Payroll/HCM App v1.1.29 — Code Review Notes

- Source base: verified v1.1.28 release.
- Payroll calculation remains in payroll-engine.js; browser/report presentation remains in app.js; persistence/migration remains in data-store.js.
- Monthly Absence Calendar filtering uses PayrollEngine.isEmployedOn across the selected calendar month, so termination/rehire visibility follows the same effective-dated employment model as payroll rather than a separate status flag.
- Amount-entered Additional Earnings are tagged amountOnly at row creation. Payslip rendering also recognises legacy amount-only additional/retro rows with zero units/rate so imported/finalised history renders consistently.
- Previous-financial-year retro labelling is display-only in app.js. Internal descriptions/source dates remain unchanged, preserving retro settlement and tax calculations.
- Annual Leave Overutilisation Recovery on resignation now uses abs(projectedBalances.annual) after current-pay rows/accruals instead of being capped to forecast-approved leave usage. The existing negative-unit balance accounting brings the deficit to zero on finalisation.
- Full Node regression suite and JavaScript syntax checks pass before packaging.
