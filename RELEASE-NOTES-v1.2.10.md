# v1.2.10 — 7 November 2026

- Removed Super Eligible from On-call Allowance in Payroll and MSS. New/open on-call entries exclude super and ignore eligibility overrides. The fixed $22.50 hourly rate is unchanged; finalised historical treatment is preserved.
- Simplified timesheet summary to Flex Balance (Max 37.5). New timesheets contain weekdays only and always open on the current pay period. Previous periods remain available; future periods cannot be selected or saved. Previously recorded weekend data is retained read-only.
- Corrected non-rostered-day flex: the first 7.5 net worked hours earn no flex, and only excess earns flex. Rostered days still use their daily roster threshold. Only explicit Flex Time Taken reduces the balance; approved carry-forward is capped at 37.5 hours. This rule replaces v1.2.9's additional-day calculation.
- Added unsaved-timesheet prompts for page/period navigation, with Save Changes, Leave Without Saving and Keep Editing. Refresh/close uses the browser's standard warning. Failed saves retain inputs; week navigation preserves the draft without prompting.
- Displayed approved leave and hours beside timesheet days. Missing-day warnings highlight past rostered weekdays without work, approved leave or flex; today, future dates, public holidays and non-rostered days are excluded. These are advisory and do not block submission or change pay.
- Added Extended Absences to the Payroll Dashboard, combining adjacent approved bookings across non-working gaps and showing roster-based return dates. Defaults are 14 calendar days for extended absence and 7 calendar days for return reminders, configurable in Settings → General.
- Current Reports To managers receive deduplicated return reminders linking to the employee's requests. Cancelled/changed leave and reporting changes remove obsolete reminders. Reminders appear in the app while it is open or on reopening; no email or external delivery is added.
- Added optional Preferred Name in Payroll Personal Details creation/editing, used in app selectors, headers and calendars. Legal first/last names remain separate and are retained on payslips, Statements of Service/Earnings and financial records. ESS/MSS details remain read-only.
- Standardised labelled status colours, Save/Cancel placement and compact employee headers with name, ID and current position, including acting roles. Cancel restores persisted data or exits an unsubmitted form; timesheet Cancel retains its unsaved-change choice.
- Long employee/position selectors (10+ available options) have name/number search, keyboard clearing/focus and no-match feedback while retaining existing scope and native selection behaviour. Available in the separate support window too.
- Payroll and MSS certification ticks retain nested-table/page scroll and checkbox focus while progress saves.
- Shared date displays now use four-digit years. Reports and previews show accessible loading placeholders, handle errors and cancel obsolete opening tasks after navigation. Data tables have hover/focus highlights and selected-row outlines; formal documents, calendar/entry grids and printed output are excluded from selection styling.

Validation is recorded in TEST-RESULTS-v1.2.10.md. Deploy the complete matching file set together. Existing browser-local data, credentials and finalised payslips are retained; stored ISO dates are unchanged. Timesheets continue to have no effect on pay, and any payment for additional work remains a separate manager/Payroll entry in Additional Earnings.

Existing limitations remain: this browser-local prototype does not provide a shared server database or server-side authorization; the earlier stale LSL entitlement-date report is unconfirmed and is not claimed fixed; bank-specific Urgent Pay CSV acceptance is unverified and no payment file has been uploaded to a bank.
